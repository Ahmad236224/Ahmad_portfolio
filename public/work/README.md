# Project screenshots

One image per project. Drop the file here, then set its path in `WORK_SHOTS`
in `src/Portfolio.jsx`. Until the value is set, the project panel shows a
labelled drop zone — never a fabricated screenshot.

Export at **1600×1000 (16:10)**, WebP, under ~200 KB.
